# Key Decisions

## Opportunity Engine

This is not a job board.

This is an opportunity creation system.

## Primary Objective

Create high-alignment opportunities by connecting people, ideas, founders, and problems.

## Success Metric

Not:

* Number of jobs found

But:

* Number of meaningful conversations started
* Number of founder connections created
* Number of opportunities created
* Number of collaborations initiated

## User Preference

Ankit prefers:

* Founder-led environments
* Future of Work
* Creator Economy
* Education
* Wellness
* Human Potential

## Work Style

High energy:

* Conceptualizing
* Ideation
* Systems thinking
* Deep research
* Problem solving
* Building new things

Low energy:

* Bureaucracy
* Repetitive execution
* Maintenance work
* Politics

## Product Philosophy

Build simple.
Learn quickly.
Refine continuously.

Avoid overengineering.
Prefer working software.
